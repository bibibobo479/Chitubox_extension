# CHITUBOX Extension

[English installation and usage](docs/README.en.md) · [Releases](https://github.com/bibibobo479/Chitubox_extension/releases) · [MIT](LICENSE)

Неофициальное расширение **CHITUBOX Basic 2.3.1 для Linux x86_64**: линейные поддержки и вращение вида жестом **Ctrl + тачпад**. Исходники открыты; CHITUBOX устанавливается отдельно.

## Установка — одна команда

Требуются уже установленный CHITUBOX Basic 2.3.1, Python **3.9+**, `curl` и Linux с **glibc 2.38+**. Не используйте `sudo`.

```bash
curl -fsSL https://raw.githubusercontent.com/bibibobo479/Chitubox_extension/main/install.py | python3 -
```

Команда загружает установщик из этого репозитория и запускает его. Если хотите предварительно проверить код, скачайте [install.py](install.py), прочитайте его и выполните `python3 install.py`.

Откройте новый ярлык **«CHITUBOX + расширения»** в меню приложений. Повторный запуск команды обновляет расширение. Обычный ярлык CHITUBOX остаётся доступен.

Если установка CHITUBOX не найдена автоматически:

```bash
python3 install.py --app "/путь/к/CHITUBOX"
```

Нужен каталог с `bin/CHITUBOX_Basic` и `lib/`. Установщик проверяет контрольные суммы двух библиотек: неизвестные сборки, даже с тем же номером версии, отклоняются. Компиляция, права администратора и установка Python-пакетов для готового релиза не нужны.

### Без интернета

Скачайте архив `chitubox-extension-linux-x86_64.tar.gz` и `SHA256SUMS` из [последнего релиза](https://github.com/bibibobo479/Chitubox_extension/releases/latest), затем:

```bash
sha256sum -c SHA256SUMS
mkdir -p chitubox-extension
tar -xzf chitubox-extension-linux-x86_64.tar.gz -C chitubox-extension
python3 chitubox-extension/install.py --app "/путь/к/CHITUBOX"
```

## Линейные поддержки

1. Откройте модель и раздел поддержек. Выберите **Regular → Add** и настройте штатные параметры поддержки: Light / Medium / Heavy, наконечник, стойку и основание.
2. Под кнопкой автоподдержек раскройте **«Линейные поддержки»**, задайте шаг в миллиметрах и включение последней точки.
3. Выберите **«Инструмент „Линия“»** либо нажмите **Ctrl+Shift+L**.
4. Наведите курсор на модель, дождитесь штатного предпросмотра и щёлкните точку 1, затем точку 2. Ряд появится с выбранными параметрами.
5. Сразу выбирайте следующую пару точек: **инструмент остаётся активным**, пока вы не переключитесь на другой режим.

| Действие | Результат |
| --- | --- |
| Выбор штатного Add / Delete / Edit | Выход из линейного инструмента |
| Повторное нажатие кнопки инструмента или Ctrl+Shift+L | Возврат к ручным поддержкам |
| Esc после первой точки | Сброс первой точки; инструмент остаётся активным |
| Esc без выбранной точки | Выход из линейного инструмента |
| Ctrl+Z / Ctrl+Y | Отмена / повтор одного ряда |
| Нажатие заголовка панели | Свернуть / раскрыть; активный инструмент сохраняется |

Точки должны лежать на одной модели и одной стороне поверхности. Промежуточные контакты проецируются на поверхность модели: ряд может проходить через **высокие выступы и углубления**, а не только по плоской поверхности. Шаг измеряется вдоль прямого отрезка между концами; это не расстояние по изгибам поверхности. Для каждого шага выбирается внешняя поверхность вдоль интерполированной нормали концов. Сквозные отверстия и позиции, где штатный алгоритм CHITUBOX не может построить поддержку, пропускаются; панель показывает количество.

Пределы: шаг 0,2–100 мм, до 500 позиций в ряду, до 2 млн треугольников; ограничение работы — 50 млн проверок «треугольник × позиция». Слишком сложные ряды отклоняются. Это инструмент для обычных поддержек, не для автоматических деревьев/Smart Support. На сложных нависающих поверхностях проверяйте полученную геометрию перед печатью.

## Ctrl + тачпад

Удерживайте **Ctrl** и ведите двумя пальцами по тачпаду — вращается вид модели. Жест без Ctrl, приближение и мышь сохраняют штатное поведение. Это вращение камеры, а не изменение ориентации печатаемого объекта.

На Wayland используется XWayland (`xcb`). Когда Qt не сообщает источник жеста, расширение читает только состояние касаний устройства Touchpad через `/dev/input/event*`. Если доступа нет, неоднозначные события остаются штатными. Установщик не меняет права устройств и не добавляет пользователя в группу `input`. На некоторых тачпадах вращение поэтому может быть недоступно.

```bash
CHITUBOX_TOUCHPAD_SPEED=0.7 ~/.local/bin/chitubox-extended
CHITUBOX_TOUCHPAD_DISABLE=1 ~/.local/bin/chitubox-extended
CHITUBOX_LINE_SUPPORT_DISABLE=1 ~/.local/bin/chitubox-extended
~/.local/bin/chitubox-extended --vanilla
```

Скорость: 0,1–4, по умолчанию 1. Для установки только линейных поддержек: `python3 install.py --no-touchpad`.

## Совместимость и ограничения

| Компонент | Поддержка |
| --- | --- |
| CHITUBOX Basic 2.3.1 Linux x86_64, проверенные библиотеки | Проверено на Arch Linux / Hyprland / XWayland |
| Другие Linux с glibc 2.38+ и той же сборкой CHITUBOX | Ожидается совместимость; отдельно не проверено |
| Windows, macOS, ARM, Flatpak, другие версии CHITUBOX | Не поддерживаются |

Расширение загружается через `LD_PRELOAD` и использует **внутренний, недокументированный API**. Файлы CHITUBOX не патчатся. После обновления библиотек на неизвестные расширения автоматически отключаются при запуске через наш ярлык. Номер версии сам по себе недостаточен: точные хеши находятся в [compatibility.json](compatibility.json).

Файлы устанавливаются в `${XDG_DATA_HOME:-~/.local/share}/chitubox-extension`, ярлык запуска — `~/.local/bin/chitubox-extended`, настройки — `${XDG_CONFIG_HOME:-~/.config}/chitubox-extension/settings.conf`.

### Удаление

```bash
python3 "${XDG_DATA_HOME:-$HOME/.local/share}/chitubox-extension/install.py" --uninstall
```

Удаляются расширение и его ярлык. CHITUBOX, проекты и настройки расширения сохраняются.
